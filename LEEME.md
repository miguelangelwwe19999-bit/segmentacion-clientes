# Dashboard - Segmentación de clientes (Caso 5)

## Archivos
- app.py                  -> la aplicación
- requirements.txt        -> librerías necesarias
- clientes_ecommerce.csv  -> COPIA AQUÍ tu archivo de datos (el mismo del notebook)

## Probar en tu computadora
1. Instala Python 3.10 o superior.
2. En una terminal, dentro de esta carpeta:
   pip install -r requirements.txt
   streamlit run app.py
3. Se abre en el navegador: http://localhost:8501

## Publicar gratis en Streamlit Community Cloud
1. Crea un repositorio en GitHub y sube: app.py, requirements.txt y clientes_ecommerce.csv.
2. Entra a https://share.streamlit.io e inicia sesión con tu cuenta de GitHub.
3. Clic en "Create app" -> elige el repositorio, la rama (main) y el archivo app.py.
4. Clic en "Deploy". En 2-3 minutos tendrás un enlace público.
